## Ход выполнения

### 1. Настройка среды разработки
Установлена Android Studio с Android SDK (API 26+). Создан эмулятор Pixel 9 с Android 15.0 (API 35).

### 2. [Структура проекта](../screenshots/structure.png)

**Параметры проекта:**
- Package: `ru.mirea.antipovni.lesson1`
- Min SDK: API 26
- Язык: Java

### 3. Изучение структуры Android-проекта

| Файл/Папка | Назначение |
|------------|------------|
| `AndroidManifest.xml` | описание компонентов и разрешений |
| `MainActivity.java` | главный экран приложения |
| `activity_main.xml` | разметка интерфейса |
| `build.gradle.kts` | конфигурация сборки |
| `res/values/` | строки, цвета, стили |
| `res/drawable/` | изображения |

### 4. Создание эмулятора
В Device Manager создано виртуальное устройство Pixel 9 с Android 15.0. Эмулятор успешно запущен и готов к тестированию.

### 5. Типы Layout-контейнеров

| Тип | Особенности |
|-----|-------------|
| **LinearLayout** | располагает элементы вертикально или горизонтально |
| **TableLayout** | организует элементы в виде таблицы (строки TableRow) |
| **ConstraintLayout** | гибкая привязка элементов друг к другу и к родителю |


### 6. Приложение [control_lesson1](../screenshots/Linear_layout.png)
Создан экран с элементами:
- `TextView` – вывод информации
- `EditText` – ввод текста
- `Button` / `ImageButton` – кнопки
- `CheckBox` – флажок
- `ImageView` – отображение изображения

Элементы размещены в `ConstraintLayout` с привязками для корректного отображения на разных экранах.

### 7. Приложение [ButtonClicker](../screenshots/Button_clicker.png)
Реализовано два способа обработки нажатий:

| Способ | Описание |
|--------|----------|
| **Анонимный класс** | создаётся объект `OnClickListener` с переопределением `onClick()` |
| **Атрибут onClick** | в XML указывается метод, который вызывается при нажатии |

Добавлен `CheckBox`, изменяющий текст при нажатии на кнопки.

### 8. Адаптация под ориентацию экрана
Создан альтернативный layout-файл для горизонтальной ориентации (`layout-land`), в котором элементы расположены оптимально для [широкого](../screenshots/Button_clicker_horizontal.png) экрана.
